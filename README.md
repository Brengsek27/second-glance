# SECOND GLANCE

A spot‑the‑difference game featuring five hand‑drawn SVG scenes and forty hidden differences. Players must find all differences between two near‑identical panels before the clock runs out.

## Scenes (8 differences each)
- Lantern Night Market
- Clockwork Observatory
- Coral Reef Window
- Alpine Cable‑Car Village
- Orbital Greenhouse

## How to Play
Click or tap either panel on a difference. Found differences are marked with a double‑ring and a check badge. The counter shows how many remain. Wrong clicks cost 5 seconds; three strikes end the scene. Hints cost 10 seconds and pulse the next difference (3 per scene). A magnifier lens follows the pointer on the right panel.

## Scoring & Stars
Earn 1‑3 stars per scene based on speed and streak bonuses. Progress is saved across the campaign.

## Keyboard Controls
- Arrow keys: move crosshair
- Tab: cycle unfound differences
- Enter/Space: mark difference
- H: hint
- P: pause
- M: mute
- R: restart scene

## Technical Notes
A dependency‑free static game lives in `game/`. All artwork is hand‑authored inline SVG generated by small painter functions. WebAudio provides sound effects. No network access required; works offline. The `main.ts` script at the repository root packages `game/` and `screenshots/` into the submission dossier.
